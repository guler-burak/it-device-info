# IT Device Info

A lightweight Python utility for retrieving useful Windows device and system information.

The project is designed as a simple IT administration tool for quickly checking hardware and network information from a Windows computer.

## Features

- Device manufacturer and model
- Serial number
- Last reboot time
- Hostname and IP address
- Network adapter and MAC address

## Technologies

- Python
- WMI
- psutil
- socket

## Requirements

- Windows
- Python 3.x

pip install wmi psutil
